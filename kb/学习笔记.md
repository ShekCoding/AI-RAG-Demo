## 1. requests 发请求

```python
import requests

requests.get("https://api.github.com/users/octocat")                         # 查用户
requests.get("https://api.github.com/search/repositories", params={"q": "pytest"})  # 查询参数
requests.get("https://api.github.com/repos/octocat/Hello-World",
             headers={"User-Agent": "my-tool"})                              # 请求头
```

- **要点**：HTTP 方法是"动作"（GET 查 / POST 建 / PUT 改 / DELETE 删），body 是"带的东西"。
- GET 一般不带 body（参数放 URL）；POST/PUT/PATCH 才带 body。
- **真实接口的两个坑**：
  1. GitHub API 要求请求头带 `User-Agent`，否则返回 403；
  2. 未认证限流 60 次/小时，带 Token（`export GITHUB_TOKEN=xxx`）后升到 5000 次/小时。

## 2. pytest 断言

```python
def test_simple_get():
    r = requests.get("https://api.github.com/users/octocat",
                     headers={"User-Agent": "api-test-learning"})
    assert r.status_code == 200   # 条件成立才通过
```

- `assert` 是测试的灵魂：后面表达式为 `True` 通过，否则标红失败。
- **命名规则**：文件名、函数名都要 `test_` 开头，pytest 才自动发现。

## 3. 参数化

```python
import pytest

@pytest.mark.parametrize("username", ["octocat", "torvalds", "gaearon"])
def test_user_exists(username):
    r = requests.get(f"https://api.github.com/users/{username}",
                     headers={"User-Agent": "api-test-learning"})
    assert r.status_code == 200
    assert r.json()["login"] == username
```

- **一个函数跑多组数据**：`parametrize` 第一个参数名要和函数参数对上，列表里每个值跑一遍。
- 这就是"数据驱动"的真身。

## 4. 封装分层

- **用例层**（`test_*.py`）：只写"测什么"。
- **封装层**（`common/http_client.py`）：管"怎么发请求、怎么断言"。

```python
# common/http_client.py
BASE_URL = "https://api.github.com"
DEFAULT_HEADERS = {"User-Agent": "api-test-learning"}  # GitHub 强制要求

def api_get(path, **kwargs):
    return requests.get(f"{BASE_URL}{path}", **kwargs)

def assert_status(resp, code=200):
    assert resp.status_code == code, f"期望 {code}，实际 {resp.status_code}"
```

```python
# 用例层
from common.http_client import api_get, assert_status

def test_simple_get():
    assert_status(api_get("/users/octocat"))
```

- **要点**：换环境、改断言规则只改封装层一处，用例不动。这是框架的本质。

## 5. 失败重试

- 插件：`pytest-rerunfailures`。
- 命令：`pytest --reruns 2 --reruns-delay 1`（失败重试 2 次，间隔 1 秒）。
- **flaky test（不稳定测试）**：用例本身没错，但网络/环境抖动偶尔挂。
- **区分**：真 bug 每次必挂；flaky 时好时坏 → 用重试解决，而不是当成 bug。

## 6. 测试报告

```bash
pytest --html=report.html --self-contained-html
```

- `--html=report.html`：报告输出文件。
- `--self-contained-html`：CSS/JS 内嵌，单文件双击即开。
- **原理**：pytest 收集结果 → 插件（pytest-html）用 jinja2 模板渲染成 HTML。
- **手动 vs 自动**：手动在命令行加参数；自动写进 `pytest.ini` 的 `addopts`。

## 7. fixture 与 Session 复用

```python
@pytest.fixture
def test_data():
    print("准备数据")      # setup
    data = {"user": "shi"}
    yield data             # ← 分界
    print("清理数据")      # teardown

@pytest.fixture(scope="session")
def client():
    s = requests.Session()  # 复用 TCP 连接（keep-alive）
    yield s
    s.close()
```

- **fixture** = 测试的前置/后置，类比 C++ 构造函数 / 析构函数。
- **yield** 之前是 setup，之后是 teardown。
- **scope**：`function`（默认，每个用例建一次）/ `module`（每文件）/ `session`（整个会话）。
- `requests.Session()` 复用连接，省掉每次三次握手开销。

## 8. 多环境配置

- `conftest.py`：pytest 自动读取的特殊文件，放共享 fixture 和自定义参数。

```python
# conftest.py
def pytest_addoption(parser):
    parser.addoption("--env", default="test", help="选择环境")

@pytest.fixture(scope="session")
def base_url(request):
    env = request.config.getoption("--env")
    return ENVIRONMENTS[env]
```

```python
# common/config.py
ENVIRONMENTS = {
    "test": "https://api.github.com",
    "staging": "https://api.github.com",
    "prod": "https://api.github.com",
}
```

- **要点**：换环境只改 `--env` 一个参数，代码一行不动。

## 9. jsonpath 断言

```python
from jsonpath import jsonpath

data = {"data": {"user": {"name": "shi"}, "orders": [{"id": 1}, {"id": 2}]}}

jsonpath(data, "$.data.user.name")    # ['shi']
jsonpath(data, "$.data.orders[*].id") # [1, 2]
```

- 语法：`$` 根、`.key` 字段、`[0]` 下标、`[*]` 全部、`..key` 递归搜索。
- **坑**：返回的是**列表**（即使单个值），要单值就 `[0]`；字段不存在返回 `False` 而非抛异常。

## 10. 配置管理 pytest.ini

```ini
[pytest]
reruns = 2
reruns_delay = 1
addopts = -v -s
testpaths = tests          # 只收集 tests/ 目录
pythonpath = .             # 让 common 包可被导入
python_files = test_*.py
```

- `addopts`：默认命令行参数（每次 pytest 自动带上）。
- **优先级**：命令行参数 > pytest.ini 配置。
- 语法规则：`[pytest]` 段落标题 + `键 = 值`，`#` 开头是注释。
